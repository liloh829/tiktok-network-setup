## TikTok 到底在检测什么

TikTok 判断你是哪国用户，依据的是设备发出来的一整套信号，主要有四类：

- **SIM 卡**：卡插着，运营商信息就会暴露你的真实所在。所以做 TikTok 的第一步是拔卡，这也是必须准备一台专用手机的原因。
- **IP 地址**：你连网用的出口。共享节点用的人一多，IP 容易被污染甚至被平台标记，很多账号“什么都没干就被限流”，根源就在这里。
- **系统语言、地区和时区**：这些参数直接决定注册时弹出哪个号段。手机语言是中文，注册页面弹出来的是 +86；改成英文、时区设到美国，弹的才是 +1。
- **GPS 定位**：定位和 IP 对不上是典型的风控特征。服务器在美国、定位却在首尔这种组合，很容易触发平台的封禁机制。

四项要同时对齐到同一个目标地区，缺哪项哪项就是短板。

## 手机端设置：iPhone 和安卓分开处理

手机端的目标只有一个：把设备重置成一台“本地人手机”。操作不复杂，但每一步都不能省，环境不吻合是限流和封号最常见的原因。

### 先准备一台专用手机

- iPhone 7 或以上，存储 16G 起，欧版美版国行都可以；
- 安卓要系统 7.0 以上、内存 3G 以上，建议 4G 内存加 32G 存储；
- 不推荐华为，谷歌框架不好装，后面下载 TikTok 会麻烦；打算做 30 台以上的矩阵群控，直接选安卓。

### iPhone 怎么设置

1. 刷机或恢复出厂设置，清掉旧数据；
2. 激活时语言选英文，地区选目标国家（比如美国）；
3. 关闭定位，关闭广告追踪（设置里的 Limit Ad Tracking）；
4. 到“设置-通用-关于本机”检查运营商，显示 not available 才算干净。

下载 TikTok 要用海外 Apple ID，注意只在 App Store 里登录，别登进系统的 iCloud。也不要几个人共用一个 ID：既有被封号的风险，操作不当还可能把手机锁成砖。

### 安卓怎么设置

恢复出厂后，语言选英文，时区改成目标国家并设为手动，关掉定位和数据发送类开关。国产机大多没有谷歌框架，要先装好 Google 三件套（Play 商店、Play 服务、服务框架），再从 Play Store 搜 TikTok，或者用 APKPure、APKMirror 这类站直接装安装包。

| 项目 | iPhone | 安卓 |
| --- | --- | --- |
| 语言 / 地区 | 英文 + 目标国家 | 英文 + 目标国家，时区设手动 |
| 定位 | 关闭 | 关闭 |
| 下载渠道 | 海外 Apple ID 登 App Store | 谷歌三件套 + Play Store，或 APKPure |
| 额外注意 | 海外 ID 只登 App Store，别登 iCloud | 部分国产机要先装谷歌框架 |

## 网络搭建：现成专线和自建服务器两条路

网络这块只有两种选择：买现成的专线服务，或者租一台海外服务器自己搭。差别主要在 IP 归属和折腾程度。

### 现成专线：省事，但 IP 是共享的

专线服务商一般把套餐按用途分好，注册养号、日常运营、直播各有对应线路。后台提取二维码，用代理客户端扫码导入就能连上，上手门槛很低。要注意两点：一是别和别人扎堆买同一款，用的人多了 IP 容易被污染或封掉；二是共享 IP 终究不归你一个人，账号做大之后稳定性要打个问号。

### 自建海外服务器：IP 独享

自己租一台海外 VPS，在服务器上部署代理面板，手机端连自己的节点。好处很直接：IP 独享、固定，一台服务器长期绑一个号，成本也比同档专线低。代价是要动手敲几条命令。以下操作仅用于跨境内容运营场景的合规搭建，流程如下：

1. 开一台目标地区的 VPS，系统选 CentOS 7.9 或类似 Linux；
2. 装 Docker 并设为开机自启；
3. 用 Docker 部署一个代理面板，生成节点信息；
4. 装 Nginx 做反向代理，把面板和节点端口套到 80/443 后面；
5. 到云控制台的安全组放行对应端口；
6. 手机装好对应客户端，扫面板二维码导入节点，连接成功后再装 TikTok。

对 TikTok 来说服务器配置要求不高，一核一G 跑一个节点绰绰有余，真正影响体验的是带宽和 IP 纯净度。

## 下载和注册：这几个坑最常见

注册环节的问题，九成出在顺序错了——环境还没检测就急着装 TikTok、急着注册，把暴露风险全留在了账号档案里。

- 装好 TikTok 后先别急着注册，连上节点做完检测（下一节）再打开；
- 打开后先刷视频，系统弹注册提示先不理，多刷几次、点几个赞，让账号有初始偏好后再注册；
- 注册时的生日必须满 18 岁，而且要记住填的日期，之后还会用到；
- 邮箱用 Outlook 或 Gmail 这类海外邮箱，不建议 163、QQ；用 Google 或 Facebook 账号登录的话，尽量挑老号；
- 一个手机号只能绑一个 TikTok 账号。

注册完也别急着发内容。先对标你想做的同类账号，刷、点赞、收藏、关注、评论，按目标地区用户的作息来，养一个星期左右再发第一条视频。

## 环境检测：两个网站确认配置没漏

检测靠两个免费网站就够了：ipip.net 看 IP 归属和时区，whoer.net 看整体伪装度，两个都过再打开 TikTok。

1. 手机浏览器打开 ipip.net，确认显示的 IP 归属地和时区与目标运营地区一致；
2. 再打开 whoer.net 看伪装度评分，按扣分原因逐项修改，目标是 100%，实在不行也要在 80% 以上；
3. 定位单独处理：iPhone 用爱思助手连电脑改虚拟定位，安卓用 FakeLocation 的免 ROOT 模式，把定位设到 IP 所在的城市。

> 两个高频扣分点：一是时区设成了自动，中午还满分、晚上就报系统时间不一致。时区必须手动，而且要对齐 IP 所在那个时区，美国本土就有好几个时区。二是 GPS 和 IP 对不上，这类组合最容易触发风控。

## 账号养起来之后：别让 IP 飘了

环境搭好只是开始，账号后面出问题，大多出在 IP 漂移上。

- 一个号绑一个固定 IP，不要到处飘；
- 偶尔掉线没事，频繁掉线就可能导致账号异常，发现掉线尽快恢复节点，别长时间裸连；
- 确实要换 IP，按这个顺序：开飞行模式 → 退出账号 → 等几个小时 → 换 IP → 关飞行模式 → 登录后先刷一会儿。偶尔换一次不影响，但别频繁换，也别在短时间内从日本直接跳到欧美这种大跨度换法；
- 想加新号，先确认第一个号已经跑通、环境设置没问题，再另起一台设备或另一个 IP。

## 常见问题

**伪装度 70% 能用吗？**
理论上 IP 没问题就影响不大，但尽量做到 80% 以上，能改的项都改掉。

**拔卡和插一张海外卡有区别吗？**
对账号流量没有明显差别。后期想定位更精准，可以插目标地区的实体卡，或者买一张能收验证码的虚拟卡。

**节点掉线后用 WiFi 登了 TikTok，账号会废吗？**
偶尔一次没事，频繁掉线才会导致异常。

**之前用日本 IP，现在想换欧美可以吗？**
只要不是切回大陆 IP，偶尔换一次不影响。别频繁换，也别短时间大跨度地换。

**一个手机能登几个 TikTok 号？**
先把一个号跑通再考虑加号。尽量一号一机一 IP，出了问题也容易定位原因。
